## Ingest integrity and recovery behavior

- Every raw/curated write uses append-only receipt directories and content hashes. Repeating an
  unchanged source returns `already_present=true` instead of rewriting history.
- Board first prints and revised SDMX snapshots have distinct dataset identities. Model readers
  remain behind the Vintage Guard and cannot import the lake directly.
- External identity, accession, tag, filename, label, unit, period, and scale contracts fail
  closed. Recovery is source- or trust-scoped; a failed lane does not require deleting good data.
- Loan-level Auto ABS documents are private runtime evidence. Only non-identifying aggregate rows
  cross the curated boundary, and no raw XML is published.
- Optional or unavailable values remain labeled: `NOT_REPORTED`, `OPTIONAL-DEGRADED`, `BLOCKED`,
  revised context, and terminal history are not converted into numbers.

coverage files, and disposable clone paths are excluded from this stable report and from Git.
